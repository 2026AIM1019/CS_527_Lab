# CS527 Lab 2 Test Cases

All `data.byte` files contain hexadecimal bytes, one byte per line. The simulator reads them with `%x`, so values such as decimal 10 must be written as `0A`, not `10`.

## How to build

```bash
make clean
make
```

## How to run a test

```bash
./executable tests/test_01/program.txt
```

The executable now automatically uses the same directory as the source program:

- `tests/test_01/program.txt`
- `tests/test_01/program.byte`
- `tests/test_01/data.byte`

This works similarly for all test directories.

## Test list

1. Fixed-size sum: expected `Data[16] = 55`
2. Complex multiplication: expected `Data[16] = 70`, `Data[20] = 85`
3. 3x3 determinant: expected `Data[36] = 37`
4. Runtime N sum: expected `Data[24] = 150`
5. 3-tap FIR: expected outputs `10, 40, 80` at `Data[16], Data[20], Data[24]`

Each test directory contains:

- `program.txt` - source program
- `data.byte` - initial memory image
- `program.byte` - compiler-generated bytecode
- `expected_program.byte` - expected bytecode for validation
- `expected_result.txt` - expected final memory results

`program.byte` may be regenerated every time the test is run. It should match `expected_program.byte`.
