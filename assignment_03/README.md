# CS527 Lab 3

This project extends the Lab 2 mini-computer with vector registers and vector instructions, and includes the required Lab 3 user-level programs:

- `tests/vector_array_add/program.txt` — vector addition of two arrays, with N a multiple of 8.
- `tests/vector_fir/program.txt` — 8-tap FIR using vector multiplication, following the assignment loop `k < N-8`.

## Build

```bash
make clean
make
```

The executable is named `executable`.

## Run one program

For a source program and a data file:

```bash
./executable tests/vector_array_add/program.txt
./executable tests/vector_fir/program.txt
```

The data file defaults to `data.byte` in the same directory as the source. The compiler writes `program.byte` beside the source, and the simulator writes the updated `data.byte` after execution.

You can also provide the data file explicitly:

```bash
./executable tests/vector_array_add/program.txt tests/vector_array_add/data.byte
```

Or execute already-generated bytecode directly:

```bash
./executable tests/vector_array_add/program.byte tests/vector_array_add/data.byte
```

## Automatic verification

Run:

```bash
make test
```

or:

```bash
python3 test_runner.py
```

The test runner:

1. Builds the complete project.
2. Compiles every test source program.
3. Compares generated `program.byte` against `expected_program.byte`.
4. Executes the simulator.
5. Checks the resulting `data.byte` values.
6. Independently calculates the Array Add and FIR expected results in Python.
7. Verifies that the Lab 3 programs actually contain the required vector opcodes.
8. Restores each test's original `data.byte` after the test.

A successful run ends with:

```text
7/7 tests passed
ALL TESTS PASSED
```

## Lab 3 memory layouts

### Vector Array Addition

- `0x000`: N
- `0x004`: Array A
- `0x004 + 4N`: Array B
- `0x004 + 8N`: Result array

The program processes eight 32-bit integers per vector operation.

### FIR

- `0x000`: N
- `0x004..0x023`: eight weights
- `0x024`: input array
- `0x100`: output array
- `k` runs from `0` through `N-9`, exactly matching `k < N-8` in the assignment.

The vector FIR uses vector load, vector multiply and vector store. Scalar additions accumulate the eight products for each output sample.
